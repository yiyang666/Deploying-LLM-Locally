## 1. 命令速查

### Windows（PowerShell）

```powershell
nvidia-smi
nvidia-smi --query-gpu=name,driver_version,memory.total,memory.free --format=csv
wsl -l -v
wsl --shutdown
wsl -d Ubuntu-24.04
```

### WSL：GPU / Docker / Toolkit

```bash
nvidia-smi
ps -p 1 -o comm=                          # 应为 systemd
sudo systemctl status docker --no-pager
docker run --rm hello-world
nvidia-ctk --version
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker
docker run --rm --gpus all nvidia/cuda:12.4.0-base-ubuntu22.04 nvidia-smi
```

### vLLM 常用

```bash
docker logs -f vllm-agent                 # 或 vllm-coder
docker stop vllm-agent && docker rm vllm-agent
curl -s http://127.0.0.1:8000/v1/models
watch -n1 nvidia-smi
```

## 2. 故障对照表

| 症状 | 优先检查 |
|------|----------|
| WSL 无 `nvidia-smi` / Failed | Windows 驱动；`wsl --shutdown` 后重试；勿在 WSL 装 Linux nvidia 驱动 |
| `hello-world` 失败 | Docker 是否 Engine；systemd；`systemctl status docker` |
| `could not select device driver ""` | 未装 Toolkit 或未 `nvidia-ctk runtime configure`；是否 snap Docker |
| 容器 CUDA 版本报错 | 镜像 CUDA &gt; 驱动支持上限 → 换低 CUDA 镜像或升级 Windows 驱动 |
| vLLM OOM | 降 `--max-model-len` / `--gpu-memory-utilization`；确认只跑一个模型 |
| 模型下载失败 | 网络、HF Token、改用 ModelScope/本地路径 |
| 外网连不上 8000 | 先本机 curl；再查 WSL 端口转发与防火墙；勿裸奔公网 |

---

## 3. 铁律回顾

1. **驱动只装 Windows**，WSL 透传使用。  
2. **Docker 用 WSL 内 Engine**，避免与 Desktop 配置打架。  
3. **先 GPU 冒烟（容器 nvidia-smi），再 vLLM。**  
4. **48GB 默认一次只驻留一个大模型**，按需切换。
