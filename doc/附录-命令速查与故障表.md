## 1. 命令速查

### Windows（PowerShell）

```powershell
wsl --status
wsl --version
wsl -l -v                                          # -l 是字母 L
wsl --install -d Ubuntu-24.04
wsl --shutdown
wsl -d Ubuntu-24.04
# 无人值守 keeper（任务计划参数同左）
# wsl.exe -d Ubuntu-24.04 --exec /bin/bash -c "exec sleep infinity"
nvidia-smi
nvidia-smi --query-gpu=name,driver_version,memory.total,memory.free --format=csv
```

### WSL：系统 / Tailscale / Docker / Toolkit

```bash
ps -p 1 -o comm=                          # 应为 systemd
systemctl is-active tailscaled
tailscale status
tailscale ip -4
sudo systemctl status docker --no-pager
docker run --rm hello-world
nvidia-ctk --version
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker
docker run --rm --gpus all nvidia/cuda:12.4.0-base-ubuntu22.04 nvidia-smi
```

### vLLM 常用

```bash
docker logs -f vllm-agent                 # 或 vllm-coder
docker stop vllm-agent && docker rm vllm-agent
curl -s http://127.0.0.1:8000/v1/models
watch -n1 nvidia-smi
```

## 2. 故障对照表

| 症状 | 优先检查 |
|------|----------|
| 「没有已安装的分发」 | WSL 有、发行版无：再 `wsl --install -d Ubuntu-24.04` |
| `wsl -1 -v` 报无效参数 | `-l` 是字母 L，不是数字 1 |
| 提示不支持 WSL1 | 若默认版本为 2，通常可忽略，继续看 `wsl -l -v` |
| 开机后远端 offline | 任务是否「系统启动时」+ keeper；勿用「用户登录时」；勿用 `/bin/true` |
| 任务跑了但发行版 Stopped | 参数/发行版名；设置里是否超时杀任务 |
| WSL 无 `nvidia-smi` | Windows 驱动；`wsl --shutdown`；勿装 Linux nvidia 驱动 |
| `hello-world` 失败 | Docker Engine；systemd；`systemctl status docker` |
| `could not select device driver ""` | Toolkit / `nvidia-ctk`；是否 snap Docker |
| 容器 CUDA 版本报错 | 镜像 CUDA &gt; 驱动上限 → 换镜像或升级驱动 |
| vLLM OOM | 降 `max-model-len`；一次只跑一个模型 |
| Tailscale offline 且 WSL Running | `systemctl status tailscaled`；勿先怪 DERP relay |

## 3. 铁律回顾

1. **WSL 运行时 ≠ Ubuntu 发行版**，两层分别验收。  
2. **驱动只装 Windows**；WSL 透传使用。  
3. **当 Server 必须管生命周期**：Task Scheduler + `sleep infinity`，服务交给 systemd。  
4. **Docker 用 WSL 内 Engine**；先容器 `nvidia-smi`，再 vLLM。  
5. **48GB 默认一次只驻留一个大模型**。
